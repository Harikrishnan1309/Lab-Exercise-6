# ALGORITHM / PROCEDURE

1. Identify a known UX problem.
2. Conduct a Crazy 8s ideation exercise to generate multiple low-fidelity solutions.
3. Select the most suitable idea from the generated solutions.
4. Create user stories based on user goals.
5. Select one user story and develop a narrative scenario.
6. Describe the user's environment, emotional state, tasks, and goals.
7. Create a task flow for completing the selected task.

9. Select an example website for information architecture.
10. Perform open card sorting by grouping related information.
11. Create a site map based on the categorized information.
12. Document the final ideas, user stories, scenario, flow diagram, card sorting, and site map.


# OUTPUT

# 1. SOLUTION IDEATION

## UX PROBLEM

Patients often find it difficult to search for a suitable doctor, find available appointment slots, and complete a hospital appointment booking quickly.

## IDEATION METHOD – CRAZY 8s

Crazy 8s is a rapid UX ideation technique used to generate multiple solutions in a short time.

Eight low-fidelity ideas were created to improve the hospital appointment booking experience.

## IDEA 1 – QUICK DOCTOR SEARCH

A simple search box that allows users to search doctors by name or specialty.

## IDEA 2 – SPECIALTY SELECTION

Users can select specialties such as:

* General Medicine
* Dental
* Pediatrics
* Cardiology

## IDEA 3 – AVAILABLE TODAY

A section that shows doctors who have appointments available on the current day.

## IDEA 4 – TIME-SLOT VIEW

Available appointments are displayed clearly under:

* Morning
* Afternoon
* Evening

## IDEA 5 – DOCTOR COMPARISON

Users can compare:

* Doctor specialty
* Experience
* Rating
* Consultation fee

## IDEA 6 – ONE-TAP REBOOKING

Users can quickly book another appointment with a doctor they previously visited.

## IDEA 7 – APPOINTMENT REMINDER

The app displays a reminder containing:

* Doctor name
* Date
* Time
* Hospital location

## IDEA 8 – EASY RESCHEDULING

Users can easily change their appointment to another available time slot.

## SELECTED IDEA

The selected solution combines:

**Doctor Search + Specialty Selection + Available Time Slots + Simple Appointment Confirmation**

This can reduce the number of steps and make appointment booking easier for patients.



# 2. CREATING USER STORIES

# 3. CREATING A NARRATIVE SCENARIO

## SELECTED USER STORY

 As a patient, I want to see available appointment slots, so that I can choose a convenient time.

## NARRATIVE SCENARIO

Priya is a 32-year-old software employee who needs to consult a doctor. She is at home after work and wants to book an appointment without calling different hospitals.

She opens the healthcare app on her smartphone and selects the required medical specialty. She feels slightly worried because she wants an appointment soon.

The app displays available doctors and appointment slots clearly. Priya selects a doctor and checks the doctor's details.

She then views the available morning, afternoon, and evening time slots. She chooses a convenient time and confirms the appointment.

After receiving the booking confirmation, Priya feels relieved and satisfied because she was able to book the appointment quickly without visiting the hospital.

## USER CONTEXT

| Category            | Details                                                                          |
| ------------------- | -------------------------------------------------------------------------------- |
| **Environment**     | At home using a smartphone after work                                            |
| **Emotional State** | Worried at the beginning and relieved after successfully booking the appointment |
| **Main Task**       | Find a suitable doctor and select an available appointment slot                  |
| **User Goal**       | Book a convenient doctor appointment quickly and easily                          |
